## 🔧 Techniques d'Optimisation

### 1. **Lambda Functions**
```python
# Avant
def equation(T):
    K = self.K_values(T, P)
    return np.sum(K * x) - 1.0

T_bubble = fsolve(equation, T_guess)[0]

# Après
T_bubble = fsolve(lambda T: np.sum(self.K_values(T, P) * x) - 1, T_guess)[0]
```

### 2. **Retour Direct**
```python
# Avant
K = np.array([comp.K_value(T, P) for comp in self.compounds])
return K

# Après
return np.array([comp.K_value(T, P) for comp in self.compounds])
```

### 3. **Assignations Multiples**
```python
# Avant
self.Tc = self.chem.Tc
self.Pc = self.chem.Pc
self.omega = self.chem.omega

# Après
self.Tc, self.Pc, self.omega = self.chem.Tc, self.chem.Pc, self.chem.omega
```

### 4. **Opérateurs Conditionnels**
```python
# Avant
if T_guess is None:
    T_guess = sum(...)

# Après
T_guess = T_guess or sum(...)
```

### 5. **Expressions Consolidées**
```python
# Avant
ratio = (alpha[i] - alpha[self.HK_idx]) / (alpha[self.LK_idx] - alpha[self.HK_idx])
d[i] = ratio * self.F * self.z_F[i]
b[i] = (1 - ratio) * self.F * self.z_F[i]

# Après
ratio = (alpha[i] - alpha[self.HK_idx]) / (alpha[self.LK_idx] - alpha[self.HK_idx])
d[i], b[i] = ratio * self.F * self.z_F[i], (1 - ratio) * self.F * self.z_F[i]
```
